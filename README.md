# @local/dsh-task-hub — 跨对话任务中心（收件箱 + 看板）

DSH 双半侧插件：聚合所有工作区会话的待确认问题（含计划待审）与任务/目标完成状态，
提供邮箱样式的收件箱页与 multica 风格的任务看板，集中处理需要人工接手的事项。

## 功能

- 页头视图切换：**收件箱** / **看板**
- 收件箱：❓待确认（含 plan-review，可内联作答）、✅任务完成、🎯目标完成；未读/已读/归档
- 「去处理」= 跳转会话 + 自动标记已读（跳转即接手）
- 看板六列：待办 / 进行中 / 待确认 / 阻塞中 / 已完成 / 已归档
  - 自动迁移：会话运行中→进行中；提问→待确认；goal blocked→阻塞中；清单全完成→已完成
  - 拖拽卡片改状态（本地持久化覆盖），卡片上「↺ 自动」恢复自动推导
  - **交接动作**（multica 工作流语义）：拖到「进行中」弹确认框发送继续指令唤醒智能体；
    进行中→已完成发送收尾指令；进行中→待办（运行中）先取消回合；待确认→其他提示仍在等待
  - 列颜色标识（背景 tint + 列头色条 + 卡片左缘色条）
  - 已归档列默认折叠为标题行（列头 ▸/▾ 展开），「已完成」列头「归档全部」一键清理堆积
- **工作区归档同步**：在工作区侧边栏归档/取消归档对话后，插件实时跟随（`ctx.workspaces.list` 订阅）
  - 看板：工作区已归档的会话强制进「已归档」列（压过手动覆盖，卡片带「工作区」小标）；拖出归档列会先解除工作区归档
  - 收件箱：该会话的全部消息自动进「已归档」Tab、退出全部/待处理与未读计数；「取消归档」联动解除工作区归档
- **搜索**：收件箱/看板页头搜索框，按标题或**对话内容关键字**（完整轮次正文）过滤；看板含任务清单内容
- **归档列防堆积**：「已归档」列头「隐藏」一键收起全部卡片（保留计数，随时「显示」）
- Node 半侧常驻检测器（每 5 秒读投影缓存），浏览器关闭也不漏事件

## 架构

- Node 半侧（lib/index.js）：读 `~/.dsh/storages/session_projcache/sessions/*.json`，
  迁移检测 → `~/.dsh/storages/task-hub/events.json`（原子写）
- 浏览器半侧（lib/client.js）：`session.list` + 逐会话 `session.projections` 补齐 +
  `/api/file` 读取事件文件 + `remote.userQuestions.answer` 内联作答 + `uiWorkspace.openSession` 跳转 +
  订阅 `ctx.workspaces.list`（工作区归档集合，inject `workspaces`/`remote.workspace`）

## 已知边界

- 权限审批为瞬态 waterfall、无持久投影，不参与看板/收件箱聚合
- 看板手动覆盖存浏览器 localStorage；完成事件存宿主侧 JSON（跨重启持久）
- 完成事件首次观察只建基线不回放历史（安装时不制造积压）
- 「待查看」通知的投递范围（订阅策略）：通过收件箱回信驱动的会话、或带清单/goal/待确认问题的会话；其余会话的轮次变化静默。可右键「静音此会话」（静音只屏蔽动态，问题/完成仍可见）
